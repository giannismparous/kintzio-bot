Συνεργασίες • Konstantinos Kintzios

Μετάβαση σε περιεχόμενο

Μενού

Για την εταιρεία σου

Βοηθώ ανθρώπους και οργανισμούς να ξεκλειδώσουν τον πραγματικό τους πλούτο, εκεί που τα KPIs συναντούν τις αξίες και την ανθρώπινη δυναμική.

Για εσένα

Όσα έκανες και κάνεις μέχρι σήμερα, δεν είναι όλα όσα μπορείς να πετύχεις αύριο. Ήρθε η ώρα να περάσεις στην επόμενη πίστα.

Πάμε;

Δε με ενδιαφέρουν τα λογότυπα για το φαίνεσθαι.

Με ενδιαφέρουν οι άνθρωποι για την ΟΥΣΙΑ.

Δε μπαίνω ποτέ σε μια εταιρεία απλώς για να «κάνω μια ομιλία».

Μπαίνω για να αλλάξω τον τρόπο που σκέφτονται, συνεργάζονται και ηγούνται οι άνθρωποί της.

Δε με ενδιαφέρει απλώς να ποστάρω το λογότυπό σου δίπλα στα υπόλοιπα. Με ενδιαφέρει να δω την ομάδα σου να λειτουργεί αλλιώς μετά από τη συνεργασία μας. Να επικοινωνεί καλύτερα, να ακούει ουσιαστικότερα, να τολμά περισσότερο, να ηγείται αποτελεσματικότερα.

Αυτό που κάνω δεν είναι «μια ομιλία» ή «ένα σεμινάριο». Είναι μια ουσιαστική εμπλοκή με τον άνθρωπο, την ομάδα, την κουλτούρα και το business model. Είναι ένα μείγμα mentoring, βιωματικού consulting και ηγετικής καθοδήγησης που φέρνει αλλαγή σε βάθος.

Σε αυτή τη διαδρομή, είχα τη χαρά να συνεργαστώ με μερικούς από τους πιο θαρραλέους οργανισμούς στην Ελλάδα. Αυτούς που δεν ψάχνουν κάποιον να πει κάτι ωραίο, αλλά κάποιον που θα τους βοηθήσει να γίνουν κάτι καλύτερο.
