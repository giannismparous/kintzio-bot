Πολιτική Απορρήτου

Η σελίδα μου είναι: kkintzios.com .

Σχόλια

Όταν οι επισκέπτες αφήνουν σχόλια στη σελίδα, συλλέγουμε τα δεδομένα που εμφανίζονται στη φόρμα σχολίων, καθώς και τη διεύθυνση IP και το όνομα του προγράμματος περιήγησης του επισκέπτη για να βοηθήσουμε στην ανίχνευση ανεπιθύμητης αλληλογραφίας.

Μια ανωνυμοποιημένη συμβολοσειρά που δημιουργείται από τη διεύθυνση email σας (ονομάζεται hash) μπορεί να παρασχεθεί στην υπηρεσία Gravatar για να δούμε αν τη χρησιμοποιείτε. Η πολιτική απορρήτου του Gravatar είναι διαθέσιμη εδώ . Μετά την έγκριση του σχολίου σας, η φωτογραφία προφίλ σας είναι ορατή στο κοινό στο πλαίσιο του σχολίου σας.

Ενσωματωμένο περιεχόμενο από άλλους ιστότοπους

Τα άρθρα σε αυτή τη σελίδα μπορεί να περιλαμβάνουν ενσωματωμένο περιεχόμενο (π.χ. βίντεο, εικόνες, άρθρα κ.λπ.). Το ενσωματωμένο περιεχόμενο από άλλους ιστότοπους συμπεριφέρεται με τον ίδιο ακριβώς τρόπο όπως αν ο επισκέπτης είχε επισκεφθεί τον άλλο ιστότοπο.

Αυτοί οι ιστότοποι μπορεί να συλλέγουν δεδομένα για εσάς, να χρησιμοποιούν cookies, να ενσωματώνουν επιπρόσθετη παρακολούθηση τρίτων και να παρακολουθούν την αλληλεπίδρασή σας με το ενσωματωμένο περιεχόμενο, συμπεριλαμβανομένης της παρακολούθησης της αλληλεπίδρασής σας αν έχετε λογαριασμό και είστε συνδεδεμένοι σε αυτόν τον ιστότοπο.

Ποια δεδομένα σας συλλέγουμε

Συλλέγουμε μόνο τα προσωπικά στοιχεία τα οποία μας παρέχετε οι ίδιοι, με τη συναίνεσή σας, προκειμέου να επικοινωνήσετε μαζί μας από τη φόρμα επικοινωνίας που βρίσκεται εδώ https://kkintzios.com/contact/ , δηλαδή το ονοματεπώνυμό σας, το email σας και το τηλέφωνο επικοινωνίας, που μας δηλώνετε. Σκοπός συλλογής τους είναι αποκλειστικά η μεταξύ μας επικοινωνία.

Με ποιον μοιραζόμαστε τα δεδομένα σας

Τα δεδομένα σας δεν τα μοιραζόμαστε με κανέναν πέραν αυτής της ιστοσελίδας και τα χρησιμοποιούμε μόνο για να επικοινωνήσουμε μαζί σας.

Πόσο διατηρούμε τα δεδομένα σας

Εάν αφήσετε ένα σχόλιο, το σχόλιο και τα μεταδεδομένα του διατηρούνται επ’ αόριστον. Αυτό γίνεται για να μπορούμε να αναγνωρίσουμε και να εγκρίνουμε αυτόματα οποιαδήποτε επακόλουθα σχόλια, αντί να τα κρατάμε σε ουρά συντονισμού.

Για τους χρήστες που εγγράφονται στην ιστοσελίδα μας (αν υπάρχουν), αποθηκεύουμε επίσης τις προσωπικές πληροφορίες που παρέχουν στο προφίλ χρήστη τους. Όλοι οι χρήστες μπορούν να δουν, να επεξεργαστούν ή να διαγράψουν τις προσωπικές τους πληροφορίες οποιαδήποτε στιγμή (εκτός από το όνομα χρήστη). Οι διαχειριστές του ιστότοπου μπορούν επίσης να δουν και να επεξεργαστούν αυτές τις πληροφορίες.

Ποια δικαιώματα έχετε στα δεδομένα σας

Εάν έχετε λογαριασμό σε αυτή τη σελίδα ή έχετε αφήσει σχόλια, μπορείτε να ζητήσετε να λάβετε ένα εξαγόμενο αρχείο των προσωπικών δεδομένων που διατηρούμε για εσάς, συμπεριλαμβανομένων τυχόν δεδομένων που μας έχετε παράσχει. Μπορείτε επίσης να ζητήσετε να διαγράψουμε οποιαδήποτε προσωπικά δεδομένα διατηρούμε για εσάς. Αυτό δεν περιλαμβάνει δεδομένα που υποχρεούμαστε να διατηρούμε για διοικητικούς, νομικούς ή λόγους ασφαλείας. Για να ασκήσετε τα δικαιώματά σας αυτά μπορείτε να μας στείλετε μήνυμα μέσω της φόρμας επικοινωνίας ή στην ηλεκτρονική διεύθυνση [email protected] .

Πού αποστέλλονται τα δεδομένα σας

Τα μηνύματα των επισκεπτών μπορεί να ελεγχθούν μέσω μιας αυτοματοποιημένης υπηρεσίας ανίχνευσης ανεπιθύμητης αλληλογραφίας.

Νομική δέσμευση

Ως υπεύθυνοι επεξεργασίας των προσωπικών σας δεδομένων, αναλαμβάνουμε την υποχρέωση να διασφαλίζουμε την τήρηση του εμπιστευτικού χαρακτήρα των προσωπικών σας δεδομένων και να εξασφαλίζουμε την από την πλευρά σας απρόσκοπτη άσκηση των δικαιωμάτων, που σας παρέχει η ισχύουσα εθνική και κοινοτική νομοθεσία που ισχύει για τη συλλογή, χρήση και αποκάλυψη των προσωπικών σας δεδομένων από εμάς, συμπεριλαμβανομένου του Ν. 4624/2019, του Γενικού Κανονισμού Προστασίας Προσωπικών Δεδομένων (ΕΕ) 2016/679 του Ευρωπαϊκού Κοινοβουλίου και του Συμβουλίου της 27ης Απριλίου 2016 και οποιωνδήποτε άλλων διατάξεων που εκάστοτε ισχύουν για την προστασία δεδομένων προσωπικού χαρακτήρα.
